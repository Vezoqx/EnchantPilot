# EnchantPilot

Аддон для Наложения чар в WoW Forever 1.60.1 (70959).

1. Скачай [EnchantPilot 0.2.60-beta](https://github.com/Vezoqx/EnchantPilot/releases/download/v0.2.60-beta/EnchantPilot-0.2.60-beta.zip).
2. Распакуй папку EnchantPilot в Interface/AddOns клиента Forever.
3. Включи аддон в списке модификаций и введи /ep. Для обновления уже загруженного аддона выполни /reload.

### Мастерская

Кнопка в шапке открывает инструменты для маршрута, бюджета, закупок и распыления, историю цен и серий, группы избранного и сохранённые заказы. После установки 0.2.60-beta перезапустите WoW, чтобы клиент загрузил новый файл аддона.
